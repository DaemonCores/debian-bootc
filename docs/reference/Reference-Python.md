## `scripts/check_upstream_pins.py`

check_upstream_pins.py — report boot-stack pins that are behind upstream.

Usage:
    python3 scripts/check_upstream_pins.py [--strict]

Reads the ``*_VER`` pins of the bootc, bootupd, ostree and composefs build
blocks in ``workflows/bootc-debs-builder/packages.yml`` and compares each with
the latest GitHub release of its upstream repository.  Outdated pins are
printed, one per line.  Nothing is bumped: a bump needs a build (and, for
bootupd, a rebase of the dpkg patch), so it stays a human decision.
With ``--strict`` the exit status is 1 when a pin is outdated (used by the
scheduled workflow); otherwise the report is informational.

### `read_pins()`

```text

    text: Content of ``packages.yml``.

Returns:
    Mapping of pin name to its pinned version string.
```

### `normalize()`

```text
Returns:
    The version without its leading ``v``.
```

### `fetch_latest()`

### `outdated()`

```text
List the pins that differ from the latest upstream release.

Args:

Returns:

```


## `scripts/gen-recipe.py`

gen-recipe.py — regenerate /etc/bootc-installer/recipe.json image list.

Usage:
    IMAGE_REGISTRY=ghcr.io/owner/repo         python3 gen-recipe.py <ctx_dir> <recipe_path>

Args:
    ctx_dir: Directory containing the Containerfile* files to scan.
    recipe_path: Path to the recipe.json to update in-place (static fields
        kept).

The script replaces only the ``imgref`` and ``images`` fields; all other fields
(branding, tour, steps, …) are preserved from the existing file.

Reads ``IMAGE_REGISTRY`` from the environment.  Defaults to the DaemonCores
registry when the variable is absent (for local/manual builds).  When ``ARCH``
is set (``amd64`` or ``arm64``), only images for that architecture are listed:
an installer ISO cannot install an image built for another CPU.

### `_build_images()`

```text
Return the image list built from the Containerfile* files in ctx_dir.

Args:
    ctx_dir: Directory containing Containerfile* files.
    registry: Container registry prefix (e.g. ghcr.io/owner/repo).
    distro_name: Distribution name read from the existing recipe.
    arch_filter: When non-empty, keep only this architecture.

Returns:
    List of image descriptor dicts ready for recipe["images"].
```

### `main()`

```text
Entry point: update the recipe.json image list.
```

## `scripts/gen_docs.py`

gen_docs.py — generate the technical reference from source comments.

Usage:
    python3 scripts/gen_docs.py [--check]

Reads the Google-style docstrings of the Python sources and the header comment
block of every shell script, and rewrites the generated region of
``docs/reference/Reference-Python.md`` and
``docs/reference/Reference-Shell.md``.
With ``--check`` nothing is written and the exit status is 1 when a page is
out of date (used by CI).
